🎞️ Dub Long Video — prices & limit

Open to all tiers. Lip-sync is switched off for long videos (see the Lip-Sync tab). A long dub is always done with Inworld, whatever engine is selected on the Voice tab. The user sees the whole estimate before anything is charged: estimate fee + analysis + processing fee + voice + one voice clone per speaker + final assembly. Analysis and processing fee are charged when the user accepts; the voice, clones and assembly only after the text has been reviewed and the exact price confirmed.

Current default: 10. Whole minutes only, at least 1 (a decimal such as 0.5 is rounded down, then raised to 1). The page /dub-long refuses longer videos and also refuses anything shorter than 20 seconds.
Current default: 2. Covers separating voices from background, transcribing, detecting speakers and translating — the heaviest server work (about four seconds of server time per second of video). Rough real cost: $0.01–0.02 per video minute, while 2 credits bring in $0.012–0.02, so this is close to break-even at the cheaper packs; 3 gives a safer margin.
Current default: 10 (0 = no fee). The same for a 2-minute and a 40-minute video; it covers the fixed work every long dub causes (loading the speech models, voice separation set-up, final assembly, temporary storage and download traffic), roughly $0.01 of real cost, so 10 credits ($0.06–0.10) leaves a clear margin. Charged together with the analysis when the user accepts the estimate, and refunded with it if the job fails. Needs the column long_dub_flat_credits in the Supabase table pricing_config: run alter table pricing_config add column if not exists long_dub_flat_credits integer; once, otherwise this one value is not saved.

🎚️ Subscription Tiers (monthly)

What /pricing and Stripe checkout actually charge. Key is the tier's permanent public ID (used by /pricing and Stripe) — renaming the tier never changes it. Voice Slots: how many named cloned voices a subscriber can keep saved at once (frees up when one is deleted). Clones/mo: a separate cap on brand-new voice clones per billing month, whatever is deleted; leave blank for no monthly cap (Voice Slots still apply). Storage: GB of finished files kept for 30 days. Pre-tier subscribers with no tier on their account fall back to a hidden legacy plan that is kept automatically.

🎙️ Which engine makes new voices?

Decides what a brand-new "Clone voice" or "Upload custom voice" uses for SHORT dubs from now on. A voice that already exists keeps working on the engine that created it — switching never breaks a saved voice, and each voice is charged at the rate of its own engine. Dub Long Video always uses Inworld. Inworld needs INWORLD_API_KEY in Railway; ElevenLabs needs ELEVENLABS_API_KEY. Cancel the ElevenLabs plan only after no saved voice depends on it.

Inworld AI — —

Used for: voice cloning and Arabic speech in Dub Long Video (always) and in short dubs (when selected above). Inworld bills by characters of speech; this page cannot read its invoice, so compare the rates below with a real Inworld invoice after a few jobs. Published prices seemed to be roughly $15–35 per million characters, far below what these rates charge.

Current default: 60. Lower = more expensive for the user (30 charges twice as many credits as 60 for the same text). 60 characters per credit = $100–$166 per million characters at the pack prices.

🎬 Lip-sync — Alibaba Wan 3.0 ALPHA —

The only lip-sync provider is Alibaba Model Studio's Wan 3.0 (wan3.0-video). VEED and Sync Labs are no longer used. Offered for short dubs only (4–15 seconds), marked Alpha on the site and in the terms. The sign-in check above only tells you the keys are set — Alibaba has no free test call. Needs DASHSCOPE_API_KEY and DASHSCOPE_WORKSPACE_ID in Railway, plus Cloudflare R2 (used for temporary files).

Current default: 40. Users choose 480p, 720p or 1080p: 480p is charged at half this price and 1080p at double (defaults 20 / 40 / 80), because Alibaba bills about 1 : 2 : 4. A 15-second clip at 720p therefore costs the user 600 credits ($3.60–$6.00).

—

Real cost to you: about $0.1153 per second of video at 720p (measured: $1.73 for a 15-second 720p test), roughly half at 480p. At 40 credits a second the margin is about 52–71% depending on the pack the user bought. Check Alibaba's price again on 1 November 2026: the 720p price was a promotion until then, and if it rises, raise the price above.

🛠️ Planned Maintenance Banner

Every update restarts the server for a short time. Use this to tell users in advance: a yellow bar appears at the top of every page from the moment you save until the "To" time, with times shown in each visitor's own time zone. Work still running at the restart has to be started again, so pick a quiet time. The notice survives the restart and disappears by itself after the "To" time.

Times are in your computer's time zone.

🔒 Site Access Gate

A password wall in front of the ENTIRE site (landing page, login, everything) while the product is being tested: visitors see an "Under Construction" message, testers with the access code get in. Turn this off before you launch. The password itself lives only in Railway's SITE_GATE_PASSWORD variable (never shown here); this switch only turns the check on or off. If that variable is not set, the gate does nothing either way.

Takes effect within about 20 seconds of saving, and can be switched off instantly without touching Railway.
