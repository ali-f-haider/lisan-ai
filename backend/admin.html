🔒 Site Access Gate

A password wall in front of the ENTIRE site — landing page, login, everything — for while the product is still being tested. Random visitors see an "Under Construction" message instead of the real site; testers with the access code get straight in. The actual password only lives in Railway's SITE_GATE_PASSWORD environment variable (never shown here) — this switch just turns enforcement of it on or off. Leave SITE_GATE_PASSWORD unset in Railway and this switch does nothing either way.

Takes effect within ~20 seconds of saving. Turn this off any time to instantly reopen the site without touching Railway.

🎙️ Voice Engine

Which engine powers voice cloning AND generation for every NEW clone from now on. A voice already cloned keeps working forever on whichever engine actually created it — switching this never breaks an existing saved voice, it only decides what a brand-new "Clone Voice" or "Upload Custom Voice" call uses going forward. Inworld needs INWORLD_API_KEY set in Railway before selecting it here.

Also decides which engine's rate fields are shown under 💵 What Each Step Actually Charges (Pricing tab).

🔔 Automatic Alert Emails

Two independent background monitors email you when something is running high. Turning either off stops that email only — polling keeps running and the Health tab below still shows live numbers either way, so you lose nothing by checking there instead of your inbox. Mainly useful if these emails are eating into your Resend account's free send quota.

Each takes effect on that monitor's next poll (every ~20 minutes), not instantly.
